# 💼 Salary Predictor – AI-Powered Salary Estimation Engine (2024)

A machine learning model that predicts salaries based on user-provided input parameters and a diverse, multi-regional dataset. This project leverages data preprocessing, visualization, clustering, and multiple classification algorithms to estimate salaries accurately, adjusted for global inflation and currency consistency.

---

## 📌 Features

* 🌍 **Global Dataset**: Normalized multi-regional salary data adjusted for inflation and base currency.
* 🧹 **Data Preprocessing**: Standardized features, handled missing values, and eliminated redundancy using **NumPy** and **Pandas**.
* 📊 **Exploratory Data Analysis (EDA)**:

  * Descriptive statistics
  * Correlation heatmap
  * Geographic salary distributions
* 🗺️ **Interactive Visualizations**:

  * World map salary visualizations using **PyCountry** and **Pyplot**
* 📉 **Dimensionality Reduction & Clustering**:

  * **t-SNE** for feature reduction
  * **K-Means** for uncovering natural salary groupings
* 🤖 **ML Models Evaluated**:

  * Logistic Regression
  * Random Forest Classifier
  * Decision Tree Classifier
  * K-Nearest Neighbors (KNN)

---

## 🛠️ Tech Stack

* **Programming Language**: Python

  * Visualization: `Matplotlib`, `Seaborn`, `Pyplot`, `PyCountry`
